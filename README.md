Personal Digital Life Dashboard (PLDD)

Project Overview

A web application to manage daily tasks, study sessions, expenses, goals, notes, and important events in one place.

Project Objectives

- Manage daily and weekly tasks.
- Track subject-wise study time.
- Record income and expenses.
- Monitor personal goals.
- Maintain notes and reminders.
- View productivity through charts and statistics.

Technologies

- Python
- Django
- HTML
- CSS
- JavaScript
- SQLite

Project Status

Initial setup — development in progress.
